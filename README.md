## Featured Projects

### [VFMS — Vehicle Fleet Management System](https://github.com/Kiruthiyan/VFMS)

A fleet operations platform developed by a team of five. It covers vehicles, trips, fuel, maintenance, rentals, and staff management, with JWT authentication, role-based access, and signed URLs for document storage.

**Built with:** Next.js · TypeScript · Spring Boot · PostgreSQL · Supabase

### [Aharam — Tuition Management System](https://github.com/Kiruthiyan/aharamm)

A Tamil-first tuition management platform with student records, QR attendance, exams, timetables, analytics, and PDF progress reports. Includes staff and student portals, role-based access, and OTP-based password resets.

**Built with:** Next.js · TypeScript · Spring Boot · PostgreSQL · Flyway · JWT

### [SkillPath — Career Guidance Platform](https://github.com/Kiruthiyan/SkillPath)

A career guidance platform co-built with a teammate to help students explore degree options. Features include an AI assistant, a Z-score checker, and support for English, Sinhala, and Tamil.

**Built with:** React · Express.js · PostgreSQL · Drizzle ORM · Google Gemini

### [NeighborNet — Disaster Coordination Agent](https://github.com/Kiruthiyan/NeighborNet)

An AI-powered disaster coordination agent designed to connect people affected by emergencies with volunteers and available resources.

**Built with:** Python · Strands Agents SDK · Multi-Agent Systems

### [Splitto — Shared Expense Manager](https://github.com/Kiruthiyan/Splitto)

An expense-splitting progressive web app with offline support and tested integer-cents calculations for handling money.

**Built with:** React 19 · TypeScript · Vite · PWA

### [YarlRiders — Transport & Tour Booking](https://github.com/Kiruthiyan/yarlriders)

A responsive portal for Jaffna–Colombo transport and tour bookings, with Tamil and English support and WhatsApp booking flows.

**Built with:** React 18 · TypeScript · Tailwind CSS · Vite
